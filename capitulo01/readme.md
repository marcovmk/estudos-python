## Capítulo 1

Neste capítulo conheci o conceito de programa e entendi que ele é formado, basicamente, por cinco operações: entrada, saída, operações matemáticas, condicionais e repetições. Essas estruturas são a base de diversas linguagens de programação; o que muda é principalmente a forma como cada linguagem as escreve. O Python se destaca por apresentar esses conceitos de uma forma mais simples.

Também fiz meu primeiro programa em Python e conheci as operações matemáticas básicas, além dos primeiros tipos de valores, como `int`, números de ponto flutuante e `string`.

Outro ponto interessante foi entender a diferença entre linguagens naturais e formais. Enquanto a linguagem humana pode ter ambiguidades, contexto, gírias e diferentes interpretações, uma linguagem de programação precisa ser estruturada e literal. O computador não entende o que você quis dizer, apenas os comandos e a sequência que foram escritos corretamente.
